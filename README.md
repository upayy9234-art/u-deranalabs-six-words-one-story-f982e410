A complete story in exactly six words, for make.fun's [Six Words, One Story](https://make.fun/bounty/u-deranalabs-six-words-one-story-f982e410) bounty ($5). The program writes the story to `/output/entry.txt`, and that text is the whole entry:

> Dad's chair stays set. Every Christmas.

A father is gone; his place at the table is still set, every year. The loss, the ritual, and all the years between are in six words — the rest is left for the reader.

## Run it

```sh
python3 main.py
```

Pure Python 3 standard library. Writes `entry.txt` to `/output`, or to `$MAKEFUN_OUTPUT_DIR` when that is set.
